# 知识架构与维护规范

本文是整个知识库的“总目录”和内容边界。新增文章前先判断它属于哪个主线；如果已有主线能承载内容，就扩充原页面或新增一个明确的实践页，不再创建平行概念页。

## 一条主学习路径

```text
基础能力
  → 模型交互
  → 知识接入（Embedding / RAG）
  → 工具与 Agent
  → 生产架构
  → 评估、安全与运维
  → 高级模型训练与研究
```

模型专区和工具专区是“选型参考”，不是第二套学习路线；AI Agent 实践是进阶学习中 Agent 主线的可运行案例，不重复解释同一套概念。

## 内容分层

| 层级 | 解决的问题 | 主页面 | 不应做的事 |
| --- | --- | --- | --- |
| 基础知识 | 建立 AI、数据、模型和安全基础 | `初级知识/` | 不提前塞入生产框架细节 |
| 应用方法 | Prompt、Embedding、RAG、微调和评估 | `进阶学习/` | 不复制 Agent 实战代码 |
| Agent 实践 | 把方法组合成工具、协作、记忆和长任务 | `AIAgent实践/` | 不再新建“Agent 原理”平行页 |
| 生产系统 | 架构、部署、观测、成本、权限和发布 | `进阶学习/LLM应用架构`、`工具专区/部署运维` | 不用单篇文章承载所有工具说明 |
| 模型与工具 | 供应商/框架能力、版本和选型 | `模型专区/`、`工具专区/` | 不把未经核验的新闻写成稳定结论 |
| 高级研究 | 训练、架构、多模态、安全和数据工程 | `高级知识/` | 不用营销文章替代论文或官方资料 |

## 重叠主题的唯一归属

| 主题 | 概念主页面 | 实践页面 | 关系 |
| --- | --- | --- | --- |
| Agent | `进阶学习/Agent智能体` | `AIAgent实践/从零构建智能体`、函数调用、多 Agent、MCP、长任务 | 概念页讲机制；实践页讲可运行闭环 |
| RAG | `进阶学习/RAG检索增强` | `AIAgent实践/RAGAgent实战` | 前者讲检索系统；后者讲 Agent 调用检索 |
| 架构 | `进阶学习/LLM应用架构` | `工具专区/部署运维`、Agent 评估与可观测性 | 架构页给全局边界；专题页给运维和观测细节 |
| 模型评估 | `进阶学习/模型评估与基准` | `AIAgent实践/Agent评估与可观测性` | 前者评估模型/任务；后者评估 Agent 轨迹和生产运行 |

## 每篇专题页的固定结构

```text
# 主题
一句话定义与边界
## 适合读者
## 核心概念
## 工作机制
## 实践步骤
## 评估与验收
## 常见误区
## 与相关专题的关系
## 参考来源与更新时间
## 资料整理状态
```

“最新趋势”不能无限追加。每条时效性内容必须带日期、来源和核验状态；无法从官方文档、论文或项目仓库确认的内容只进入候选资源库，不进入正文。

## 更新和合并规则

1. 先搜索现有专题和本规范中的归属表，再决定新增还是修改。
2. 新内容优先合并到主页面；只有当读者、产出物或验证方式明显不同，才新增实践页。
3. 旧页面不删除知识，只将重复概念改成摘要和指向主页面，避免两个页面分别维护同一事实。
4. 模型名称、价格、上下文、排行榜、Star 数和版本号必须标记获取日期，且优先使用官方来源。
5. 采集脚本只管理候选资源和状态区块；人工核验后的结论才进入正文。
6. 每次合并后运行 `npm run audit`、`npm run build`，并检查主页面、导航、侧边栏和本地链接。
