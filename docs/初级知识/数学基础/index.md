# 数学基础

学习 AI 不需要先掌握全部高等数学，但需要知道常见公式在回答什么问题、输入输出的维度是什么，以及结论成立需要哪些假设。本页给出机器学习和大模型学习中最常用的数学骨架。

## 学习目标

读完本页后，你应该能够：

- 看懂向量、矩阵、张量的形状，并检查矩阵乘法是否成立。
- 区分概率、模型置信度和经过校准的正确率。
- 理解损失函数、梯度、学习率和反向传播的关系。
- 解释熵、交叉熵、KL 散度和困惑度的用途与边界。
- 知道什么时候公式的平均值会掩盖数据分布、分组差异或不确定性。

## 线性代数

### 向量、矩阵与张量

| 对象 | 直觉 | 常见形状 |
|------|------|----------|
| 标量 | 一个数 | `[]` |
| 向量 | 一组有顺序的数 | `[features]` |
| 矩阵 | 二维数表 | `[rows, columns]` |
| 张量 | 更高维数组 | `[batch, sequence, hidden]` |

AI 系统通常先把文本、图像或业务记录编码为数值表示。向量本身没有天然语义；只有在给定编码方法、训练目标和相似度度量后，向量距离才可能反映任务中的相似性。

### 维度追踪

矩阵乘法要求相邻维度一致：

```text
X: [batch, input_dim]
W: [input_dim, output_dim]
XW: [batch, output_dim]
```

Transformer 中常见的输入形状是 `[batch, sequence, d_model]`。线性投影只改变最后一个维度，批次和序列维度通常保留。先标形状再看公式，是排查模型代码错误的有效方法。

### 点积与余弦相似度

点积同时受方向和向量长度影响；余弦相似度只比较方向：

```text
dot(x, y) = sum(x_i * y_i)
cosine(x, y) = dot(x, y) / (norm(x) * norm(y))
```

当向量已经做 L2 归一化时，点积与余弦相似度给出相同排序。不能脱离模型说明随意替换距离函数，因为有些模型用点积训练，有些模型依赖归一化后的余弦距离。

## 概率与统计

### 条件概率与贝叶斯公式

条件概率表示“已知 B 后 A 发生的概率”：

```text
P(A | B) = P(A and B) / P(B)
P(A | B) = P(B | A) * P(A) / P(B)
```

贝叶斯公式描述如何用证据更新概率分布。把“预训练知识 + 微调数据”直接等同于“先验 + 后验”只是类比，并不意味着普通神经网络微调就是严格的贝叶斯推断。

### 期望、方差与抽样

- **期望**描述随机变量的平均水平。
- **方差和标准差**描述波动大小。
- **分位数**适合描述偏斜分布和尾部风险。
- **置信区间**表达估计的不确定性，而不是单次样本落入区间的概率。

只报告平均准确率可能掩盖小样本人群、长尾类别、不同设备或不同时间段的失败。评估时应同时查看样本量、分布、分组指标和波动范围。

### 概率不等于可靠置信度

Softmax 会把 logits 转成和为 1 的数值，但这不保证“输出 0.8 的样本中恰好有 80% 正确”。这种对应关系称为**校准**，需要用可靠性图、ECE、Brier score 等方法单独检验。分布变化后，原有校准也可能失效。

## 微积分与反向传播

### 导数和梯度

- 一元函数的导数描述局部变化率。
- 多元函数对每个变量的偏导数组成梯度。
- 梯度指向函数局部增长最快的方向，梯度下降沿其反方向更新参数。

最基本的更新式是：

```text
theta_next = theta - learning_rate * gradient
```

### 链式法则

神经网络由许多函数复合而成。反向传播应用链式法则，从损失向前逐层计算每个参数的梯度。自动求导免去了手算，但不会替你保证损失定义、张量形状或数值范围正确。

### 梯度消失与爆炸

深网络中反复相乘可能让梯度过小或过大。合理初始化、残差连接、归一化、梯度裁剪和门控结构可以缓解问题，但没有一种方法能在所有架构和训练设置中“彻底解决”它。

## 优化

### 损失函数

| 任务 | 常见目标 | 注意事项 |
|------|----------|----------|
| 回归 | MSE、MAE、Huber | MSE 对大误差更敏感；MAE 在 0 点不可导但可用次梯度优化 |
| 分类 | 交叉熵 | 类别不均衡时还要看采样、权重和任务指标 |
| 表示学习 | 对比损失、Triplet loss | 正负样本构造会显著影响结果 |
| 蒸馏 | KL 散度、软标签交叉熵 | 温度和教师偏差会传递给学生 |
| 偏好优化 | DPO 等偏好损失 | 不需要单独训练奖励模型，不等于不需要偏好数据或参考策略 |

训练损失是优化目标，不一定等于业务目标。例如，较低的语言模型损失不保证事实准确、引用可靠或工具调用安全。

### 优化器与学习率

- **SGD/动量 SGD**结构简单，在部分视觉和大规模训练任务中仍很有竞争力。
- **Adam/AdamW**对不同参数自适应缩放梯度，常用于 Transformer；AdamW 将权重衰减与梯度更新解耦。
- **Warmup、余弦衰减和阶梯衰减**都是调度策略，是否更好取决于模型、批大小和训练预算。

AdamW 不保证比 SGD 收敛更快，也不自动防止过拟合。优化器、正则化和泛化能力应通过验证集与消融实验判断。

### 非凸优化

深度网络的损失面通常是非凸的。实践中的目标不是证明找到全局最优，而是获得在独立数据上表现良好、训练稳定且可复现的参数。随机种子、数据顺序、批大小和数值精度都会影响结果。

## 信息论

### 熵

熵衡量分布的不确定性：

```text
H(p) = -sum(p_i * log(p_i))
```

分布越均匀，熵通常越高；概率集中在少数结果时，熵较低。

### 交叉熵与 KL 散度

```text
CrossEntropy(p, q) = -sum(p_i * log(q_i))
KL(p || q) = sum(p_i * log(p_i / q_i))
CrossEntropy(p, q) = H(p) + KL(p || q)
```

KL 散度不对称，也不满足三角不等式，因此不是严格意义上的距离。

### 困惑度

语言模型常用困惑度衡量 token 预测的不确定性：

```text
perplexity = exp(average cross-entropy)
```

困惑度只有在相同数据、分词器和评估协议下才适合直接比较。较低困惑度也不必然意味着更好的指令遵循、推理或事实性。

## 数值精度与训练稳定性

| 精度 | 常见用途 | 风险 |
|------|----------|------|
| FP32 | 稳定基线、部分累加和主权重 | 显存和计算开销较高 |
| FP16 | 混合精度训练与推理 | 动态范围较小，训练时常需 loss scaling |
| BF16 | 训练与推理 | 指数范围接近 FP32，但有效数字较少 |
| INT8/INT4 | 量化推理或量化感知训练 | 质量损失依模型、层和校准数据而变 |

混合精度的实际加速取决于硬件、算子、通信和内存瓶颈，不能笼统承诺“速度翻倍”。量化后的质量也必须在目标任务上复测。

## PyTorch 最小示例

```python
import torch
import torch.nn.functional as F

# 线性代数：检查矩阵形状
x = torch.randn(32, 768)
weight = torch.randn(768, 10, requires_grad=True)
logits = x @ weight

# 概率：每行 softmax 后和为 1
probabilities = F.softmax(logits, dim=-1)
assert torch.allclose(probabilities.sum(dim=-1), torch.ones(32))

# 损失与自动求导
targets = torch.randint(0, 10, (32,))
loss = F.cross_entropy(logits, targets)
loss.backward()

print(loss.item(), weight.grad.shape)
```

这段代码只验证计算链成立。要判断模型是否有效，还需要独立数据、合适指标、基线和误差分析。

## 常见误区

- **向量维度越高越好**：更高维度会增加存储与计算，质量取决于训练目标和数据。
- **Softmax 概率就是正确率**：未经校准时，两者不能直接等同。
- **损失下降说明产品效果变好**：损失与业务指标可能不一致，还可能出现过拟合。
- **工具成熟后不需要数学**：工具减少了手算，但维度、数据分布和评估假设仍决定结果是否可信。
- **一个最优优化器适合所有任务**：优化器与调度器需要在具体训练设置中比较。
- **只看一次运行的最好分数**：应报告重复实验、方差和选择规则，避免挑选偶然结果。

## 学习顺序

1. 向量、矩阵、矩阵乘法、范数和余弦相似度。
2. 均值、方差、条件概率、抽样和置信区间。
3. 导数、偏导数、梯度和链式法则。
4. 损失函数、梯度下降、正则化和学习率。
5. 熵、交叉熵、KL 散度和困惑度。
