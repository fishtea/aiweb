# 人工智能入门

人工智能是让机器完成感知、预测、决策、生成或执行任务的技术集合。学习 AI 不需要先背模型名单，应先建立“问题、数据、模型、评估、部署”的完整闭环。

## 适合读者

零基础学习者、产品和业务人员，以及准备进入机器学习/大模型开发的工程师。

## 核心概念

| 概念 | 解决的问题 |
| --- | --- |
| 机器学习 | 从数据中学习规律，用于预测或分类 |
| 深度学习 | 用多层神经网络学习复杂表示 |
| 生成式 AI | 生成文本、图像、音频、视频或代码 |
| 大语言模型 | 通过 Transformer 和大规模数据建模文本与工具交互 |
| Agent | 让模型在目标、工具和环境约束下执行多步任务 |

## 一条学习路径

1. 补齐 [数学基础](/初级知识/数学基础/) 与 [Python 与数据处理基础](/初级知识/Python与数据处理基础/)。
2. 学习 [机器学习基础](/初级知识/机器学习基础/) 和 [模型训练与评估基础](/初级知识/模型训练与评估基础/)。
3. 进入 [深度学习入门](/初级知识/深度学习入门/) 和 [大语言模型基础](/初级知识/大语言模型基础/)。
4. 用 [提示词入门](/初级知识/提示词入门/)、[RAG](/进阶学习/RAG检索增强/) 和 [Agent](/进阶学习/Agent智能体/) 完成第一个应用。
5. 用自己的数据评估质量、成本、延迟、安全和可维护性。

## AI 系统的通用闭环

```text
定义问题 → 收集/清洗数据 → 选择基线 → 训练或调用模型
    → 离线评估 → 小流量上线 → 监控反馈 → 迭代数据和系统
```

## 常见误区

- 把模型参数量或排行榜当成业务效果。
- 没有基线和测试集就声称“效果提升”。
- 只关注生成结果，不记录成本、延迟、失败和安全事件。
- 把 RAG、微调和 Agent 当成可以互相替代的万能方案。
- 将未经核验的“最新趋势”当成稳定事实。
