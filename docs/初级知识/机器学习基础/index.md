# 机器学习基础

机器学习用数据拟合从输入到输出的规律。入门阶段最重要的不是算法数量，而是能建立可靠的训练、验证、测试和反馈闭环。

## 学习目标

- 能区分监督学习、无监督学习和强化学习。
- 能完成数据清洗、特征处理、训练、评估和误差分析。
- 能用简单基线判断复杂模型是否真的带来收益。

## 基本流程

```text
问题定义 → 数据划分 → 特征/表示 → 训练基线 → 验证调参
    → 测试集一次性评估 → 误差分析 → 部署监控
```

训练集用于学习，验证集用于选择方案，测试集只在最终确认时使用。任何在测试集上反复调参的做法都会造成数据泄漏。

## 常见任务与指标

| 任务 | 常见指标 | 注意事项 |
| --- | --- | --- |
| 分类 | Accuracy、Precision、Recall、F1、AUC | 类别不平衡时不要只看 Accuracy |
| 回归 | MAE、MSE、RMSE、R² | 关注异常值和业务容忍区间 |
| 聚类 | 轮廓系数、人工检查 | 没有标签时必须结合业务解释 |
| 排序/推荐 | NDCG、MRR、Recall@K | 离线指标不等于线上转化 |

## 从基线到迭代

1. 先用规则、均值、线性模型或树模型建立可解释基线。
2. 记录数据版本、特征、随机种子、代码和指标。
3. 按错误类型切分样本，判断问题来自数据、特征、目标定义还是模型。
4. 只改变一个主要变量，并保留对照实验。
5. 上线后监控数据漂移、延迟、成本和真实反馈。

## 与深度学习和 LLM 的关系

深度学习是机器学习的一类方法；LLM 是以 Transformer 为核心、在大规模数据上训练的生成模型。RAG、Agent 和微调仍然需要机器学习的评估、数据治理和实验纪律。

## 常见误区

- 训练集分数很高就认为模型可用。
- 先选复杂算法，再去寻找适合它的数据。
- 混用训练、验证和测试数据。
- 只调模型参数，不修正标签、目标和评估指标。
