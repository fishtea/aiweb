# 深度学习入门

深度学习使用多层神经网络从数据中学习表示。理解张量、前向传播、损失函数、反向传播和优化器，就能读懂大多数现代模型训练代码。

## 前置知识

建议先完成 [数学基础](/初级知识/数学基础/)、[Python 与数据处理基础](/初级知识/Python与数据处理基础/) 和 [机器学习基础](/初级知识/机器学习基础/)。

## 核心机制

```text
输入 → 多层网络前向计算 → 损失函数
                 ↑              ↓
           参数更新 ← 反向传播 ← 梯度
```

- **层和参数**：线性层、卷积层、注意力层等变换输入表示。
- **损失函数**：把任务目标转成可优化的数值。
- **反向传播**：用链式法则计算参数梯度。
- **优化器**：SGD、Adam 等方法根据梯度更新参数。
- **泛化控制**：数据增强、正则化、早停、验证集和预训练。

## 架构地图

| 架构 | 典型任务 | 关键理解 |
| --- | --- | --- |
| MLP | 表格数据、分类回归 | 层、激活函数和参数更新 |
| CNN | 图像、局部模式 | 卷积、步幅、池化和感受野 |
| RNN/LSTM | 序列建模 | 状态传递和长依赖限制 |
| Transformer | 文本、多模态、生成 | 注意力、位置编码和并行训练 |
| 扩散模型 | 图像和多模态生成 | 加噪、去噪和条件控制 |

## 最小实践闭环

1. 准备可复现的数据集和训练/验证划分。
2. 用小模型过拟合少量样本，确认代码和梯度正确。
3. 记录损失、核心指标、学习率、显存和训练时间。
4. 在验证集上调整配置，最终只使用一次测试集。
5. 保存模型、配置、依赖和评估结果，确保可以重现。

## 与 LLM 应用的关系

使用 LLM API 通常不需要自己训练 Transformer，但仍要理解 token、上下文、Embedding、微调和推理成本；这些概念决定 RAG、Agent 和模型部署的边界。

## 常见误区

- 训练不收敛时只增加模型规模，不检查数据和损失。
- 没有基线、随机种子和版本记录。
- 把训练集指标当成泛化能力。
- 只学习框架 API，不理解张量形状和评估逻辑。
