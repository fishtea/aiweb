# AI 伦理安全与隐私

AI 系统的风险来自模型、数据、工具和使用环境。安全不是上线前的一次审核，而是贯穿设计、开发、发布和运营的持续过程。

## 主要风险

偏见与歧视、幻觉、隐私泄露、版权和数据授权、提示注入、越权工具调用、自动化副作用、不可解释和责任不清。

## 实用基线

1. 明确用途、禁止用途、受影响人群和人工接管点。
2. 收集最少必要数据，脱敏并限制访问、保存和导出。
3. 对模型输入、检索资料、工具参数和输出分别做校验。
4. 高风险决定保留人工复核，不让模型单独完成不可逆动作。
5. 记录版本、来源、评估、审批、错误和用户反馈，支持撤销。

## 隐私与安全检查

检查是否把个人信息送入第三方 API；日志是否脱敏；租户是否隔离；外部文档是否可能注入指令；工具是否最小权限；删除请求是否真正清除缓存、索引和备份。
