# 自然语言处理基础

自然语言处理让机器处理文本、语音和语言结构。现代 LLM 建立在 NLP 基础之上，但传统的分类、抽取、检索和评估方法仍然重要。

学习重点是把自然语言任务转成可验证的数据、指标和系统边界，而不是记住模型名称。

## 任务地图

| 任务 | 输出 |
| --- | --- |
| 分类 | 类别、意图、情感或风险标签 |
| 序列标注 | 实体、词性、时间和字段范围 |
| 信息抽取 | 结构化字段、关系和事件 |
| 检索/排序 | 相关文档和结果顺序 |
| 生成 | 摘要、翻译、改写、问答和对话 |

## 核心概念

分词/token、词或句向量、上下文、注意力、语言模型、训练/验证/测试和评估指标。中文任务要特别关注分词、领域术语、长文本和数据偏差。

## 实践流程

1. 定义任务、标签、错误成本和评估集。
2. 用规则或简单模型建立基线。
3. 选择预训练模型、Embedding、RAG 或生成 API。
4. 按错误类型分析数据、Prompt、检索和模型问题。
5. 记录版本、来源、延迟、成本和隐私边界。

## 常见误区

- 只看流畅度，不检查事实和字段准确率。
- 训练/测试数据混用。
- 把 Embedding 相似度当成语义真值。
- 忽略领域术语、否定词、时间和权限。
