# 多模态模型

多模态模型处理文本、图像、音频、视频或结构化界面的组合输入输出。学习重点是模态对齐、信息质量、任务评估和部署成本，而不是模型名称列表。

## 基本架构

```text
模态输入 → 编码/分词 → 共享表示或跨模态注意力 → 任务头/生成器
```

- 视觉编码器把图像或视频转换为视觉 token。
- 音频编码器把波形或频谱转换为时间序列表示。
- 对齐层让不同模态进入共同语义空间。
- 生成模型结合上下文完成描述、问答、抽取或动作决策。

## 任务地图

| 任务 | 评估重点 |
| --- | --- |
| 图像理解/OCR | 字段准确率、空间关系和小字鲁棒性 |
| 图文问答 | 答案正确性、引用和拒答质量 |
| 视频理解 | 时间顺序、事件定位和长视频采样 |
| 文生图/视频 | 指令遵循、内容一致性和安全 |
| GUI/视觉 Agent | 元素定位、动作成功率和误操作风险 |

## 选型与部署

选择时记录输入分辨率、上下文长度、输出模态、延迟、吞吐、价格/显存、隐私、许可证和 SDK 支持。图像越大、视频越长、音频越久，Token 或计算成本通常越高；必须用目标数据做压力测试。

## 数据与安全

- 保留媒体来源、版权、时间和处理版本。
- 对人脸、语音、屏幕和文档中的敏感数据做脱敏与访问控制。
- 不把模型对图像的猜测当作事实，关键字段要回到原图或人工复核。
- 视觉 Agent 的点击、输入和提交动作默认需要更严格的审批和回滚。

## 实践闭环

1. 定义模态、任务、输出格式和不可接受错误。
2. 建立覆盖清晰/模糊、遮挡、不同语言和恶意输入的评估集。
3. 先跑通单模态基线，再加入跨模态输入。
4. 记录媒体预处理、模型版本、Token/帧数、延迟和失败样例。
5. 上线前做权限、版权、隐私和误操作演练。
