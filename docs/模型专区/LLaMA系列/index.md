# LLaMA 系列

LLaMA 是 Meta 的开源模型系列。本页只保留部署与评估边界；具体权重、许可证和版本以 [Meta Llama 官方页面](https://www.llama.com/)为准。

## 适合场景

本地/私有化推理、研究、微调和需要控制模型权重的应用。部署前必须核对许可证、硬件和推理引擎支持。

## 选型要点

比较尺寸、上下文、语言、量化、工具调用、显存、吞吐和社区支持。用真实任务测试中文、代码、RAG、结构化输出和安全拒答，不用参数量替代质量评估。
