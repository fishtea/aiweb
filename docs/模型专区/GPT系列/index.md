# GPT 系列

GPT 是 OpenAI 的模型系列。本页只保留集成和评估边界；具体模型 ID、价格、上下文、工具和弃用计划以 [OpenAI 官方模型文档](https://developers.openai.com/api/docs/models) 为准。

## 适合场景

通用文本、代码、结构化输出、工具调用和多模态应用。模型选择应由目标任务、延迟、预算、数据边界和评估结果决定。

## 集成要点

- 锁定模型 ID 和 API 版本，记录获取日期。
- 使用 Responses/工具调用的结构化 schema，并在服务端再次校验。
- 对推理模型区分可见答案、工具轨迹、Token 和延迟，不能只看最终文本。
- 对高风险写操作加入权限、审批、幂等和回滚。

## 评估维度

任务正确率、指令遵循、结构化输出、工具调用、引用忠实度、拒答安全、首 token、完整延迟、Token 成本和速率限制。升级必须保留对照集和回滚模型。
