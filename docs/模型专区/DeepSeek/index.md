# DeepSeek

DeepSeek 是中文和开源模型生态中的重要系列。本页聚焦选型、部署和评估，不固化会快速变化的型号、价格或排行榜；请以 [DeepSeek 官方平台](https://platform.deepseek.com/) 和[官方仓库](https://github.com/deepseek-ai)为准。

## 适合场景

中文对话、代码、推理和私有化部署。实际效果取决于模型版本、量化、提示词、上下文、硬件和任务数据。

## 选型与部署

- API 集成：锁定模型 ID、超时、重试、限流和费用预算。
- 本地部署：核对权重许可证、显存、量化质量、推理引擎和并发。
- Agent：单独测试函数调用、结构化输出、工具参数和错误恢复。
- RAG：测试中文分词、召回、引用和长文档中段信息。

## 评估维度

中文/英文质量、代码测试通过率、推理正确率、工具调用准确率、延迟、Token、显存、量化退化和安全拒答。所有比较要保持数据、Prompt、工具和评估协议一致。
