# Claude 系列

Claude 是 Anthropic 的模型系列。本页只说明选型方法和稳定的集成边界；具体可用模型、价格、上下文、区域和工具能力以 [Anthropic 官方模型文档](https://docs.anthropic.com/en/docs/about-claude/models) 为准。

## 适合场景

长文档分析、文本生成、代码、结构化抽取和需要工具调用的应用。是否适合你的任务，应由真实评估集决定，而不是由模型名称决定。

## 集成要点

- 固定模型 ID，不在生产中依赖未锁定的别名。
- 使用结构化输出和服务端 schema 校验，避免把自然语言当 API 参数。
- 对长上下文测量中段召回、引用忠实度、延迟和成本。
- 对工具调用记录参数、权限、结果和人工审批。

## 评估维度

质量、指令遵循、代码/领域正确率、工具调用准确率、拒答质量、延迟、Token 成本、速率限制和数据处理边界。模型升级必须保留旧版本对照和回滚方案。
