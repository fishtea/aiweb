# Qwen 系列

Qwen 是阿里巴巴的开源与商业模型系列。本页聚焦中文、代码、多模态和本地部署的选型方法；具体型号、许可证和能力以 [Qwen 官方文档](https://qwen.readthedocs.io/) 与[官方仓库](https://github.com/QwenLM)为准。

## 适合场景

中文应用、代码、推理、Embedding、视觉/音频和私有化部署。不同尺寸、量化和推理引擎的实际表现差异很大。

## 选型要点

- 明确 API、开源权重或本地运行边界。
- 核对许可证、商用限制和权重来源。
- 测试中文质量、工具调用、RAG 引用、长上下文和量化退化。
- 用目标硬件压测显存、吞吐、P95 延迟和并发。
