# Stable Diffusion

Stable Diffusion 代表一类可本地运行、可控性较强的图像生成模型与工作流生态。本页不固化具体版本和商业宣传，模型卡、许可证和参数以[官方发布](https://stability.ai/)及权重页面为准。

## 工作流

```text
文本/图像条件 → 编码 → 采样/去噪 → 解码 → 放大/修复/控制 → 质量与安全检查
```

## 选型与实践

- 明确文生图、图生图、局部重绘、控制和放大任务。
- 记录模型、VAE、LoRA、ControlNet、采样器、步数、分辨率和随机种子。
- 先建立固定提示词与参考图评估集，再比较质量、速度、显存和一致性。
- 核对训练数据、输出用途、版权、人物肖像和内容安全边界。

## 部署

ComfyUI 适合可视化和可复现工作流；本地部署要压测显存、批量、队列、失败恢复和模型缓存。生产环境应隔离上传文件、限制插件和记录生成参数。
