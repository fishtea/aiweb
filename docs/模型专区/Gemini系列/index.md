# Gemini 系列

Gemini 是 Google 的多模态模型系列。本页不维护易过期的型号排行榜；具体模型、价格、上下文、模态和配额以 [Google AI 官方模型文档](https://ai.google.dev/gemini-api/docs/models) 为准。

## 适合场景

文本与图像理解、长文档、多模态抽取、代码和结构化生成。视频、音频和高分辨率输入要单独评估成本、采样策略和延迟。

## 集成要点

- 锁定模型 ID、API 版本和安全配置。
- 对多模态输入记录媒体来源、尺寸、帧数、预处理和权限。
- 对结构化输出做 JSON/schema 校验，不把模型文本直接写入业务系统。
- 对长上下文测试首尾与中段信息召回，不把窗口大小等同于有效记忆。

## 评估维度

分别测试文本、图像、音频、视频、工具调用、引用忠实度、拒答、安全、延迟和费用。升级时保留多模态样例和人工复核记录。
