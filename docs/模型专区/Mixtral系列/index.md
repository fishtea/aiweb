# Mixtral 系列

Mixtral 是 Mistral 生态中的稀疏专家模型路线。本页关注 MoE 模型的选型和部署取舍；具体型号、许可证和 API 以 [Mistral 官方文档](https://docs.mistral.ai/)为准。

## MoE 的工程含义

模型总参数量不等于每个 token 的计算量。稀疏路由可以提高容量与计算的分离度，但会带来专家负载、通信、批处理和量化等工程问题。

## 选型要点

测量任务质量、路由稳定性、显存、吞吐、P95 延迟、并发、工具调用和量化退化。不要只根据“参数更大”或单一 benchmark 选择。
