# AutoGPT

AutoGPT 是自主任务型 Agent 项目。它适合用来理解目标分解、工具调用和自主循环，但不应直接当作生产架构。项目版本和能力变化较快，请以[官方仓库](https://github.com/Significant-Gravitas/AutoGPT)为准。

## 适合学习什么

- 目标、计划、行动、观察和终止条件。
- 工具注册、权限、预算、重试和人工接管。
- 为什么“无限自主”会带来成本、循环和副作用风险。

## 生产使用前的改造

1. 将开放式目标拆成可验收步骤。
2. 限制工具、网络、文件和预算权限。
3. 保存 checkpoint、trace 和幂等键，支持暂停和恢复。
4. 对发布、删除、支付和外部通信增加审批。
5. 用真实评估集验证完成率、成本、延迟和安全。
