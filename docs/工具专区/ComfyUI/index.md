# ComfyUI

ComfyUI 是节点式生成工作流工具，适合把模型、采样、控制、放大和后处理组合成可复现图/视频流程。具体节点和版本以[官方仓库](https://github.com/Comfy-Org/ComfyUI)为准。

## 工作流原则

- 固定模型、节点版本、参数、种子和输入素材。
- 将下载模型、插件和自定义节点视为供应链依赖，先审查来源和许可证。
- 用小尺寸/低步数验证流程，再测质量、显存、耗时和批量。
- 对上传图片、人物、版权和生成内容设置安全与隐私边界。

## 生产检查

队列、显存、并发、失败恢复、缓存、文件隔离、访问控制、输出保留和审计都需要独立设计。演示工作流不能直接视为生产服务。
