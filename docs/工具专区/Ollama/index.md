# Ollama

Ollama 用于本地下载、管理和运行模型，适合个人开发、原型和受控的离线场景。它简化模型运行，但不自动解决数据权限、服务可靠性、许可证或生产监控。具体命令以[官方文档](https://docs.ollama.com/)为准。

## 适合场景

本地验证模型、离线实验、轻量 API、开发调试和对数据外发敏感的原型。高并发生产推理需额外评估模型服务和运维方案。

## 实施步骤

1. 从可信来源确认模型名称、许可证、大小和量化方式。
2. 在隔离目录下载并记录模型版本、哈希和日期。
3. 用固定样例测试质量、上下文、工具调用、延迟和内存。
4. 为本地 API 设置访问边界、日志脱敏和资源限制。
5. 升级模型或运行时前保留可回滚版本。

## 常见误区

- “本地运行”不等于没有隐私和安全责任。
- 只看模型文件大小，不测上下文、并发和内存。
- 从不明仓库下载模型或模板并直接执行。
- 把开发机配置复制到生产，忽略监控和故障恢复。
