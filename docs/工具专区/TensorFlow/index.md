# TensorFlow

TensorFlow 是端到端机器学习平台，覆盖张量、Keras、数据管线、训练、部署和端侧推理。具体 API 与安装矩阵以[官方文档](https://www.tensorflow.org/guide)为准。

## 适合场景

已有 TensorFlow/Keras 生态、需要端侧部署或使用其数据与服务工具链的项目。新项目应根据团队经验、模型生态和部署目标与 PyTorch 对比。

## 工程检查

- 固定 Python、CUDA、驱动、TensorFlow 和模型版本。
- 测试数据管线、训练恢复、混合精度、显存、吞吐和延迟。
- 评估 SavedModel/Serving/端侧转换后的质量和算子兼容性。
- 记录数据、配置、权重、依赖和许可证，保留回滚环境。
