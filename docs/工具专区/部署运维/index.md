# AI 应用部署运维

部署运维把通过评估的 AI 应用稳定地运行起来。重点是版本、权限、可观测性、成本、降级和恢复，而不是把模型服务直接暴露到公网。

## 上线前检查

- 模型、Prompt、工具、检索索引和安全配置已版本化。
- API key、用户数据和日志已脱敏，权限按租户和任务隔离。
- 有超时、重试、限流、缓存、预算和降级策略。
- 关键写操作有审批、幂等、审计和回滚。
- 真实评估集、边界样例和压力测试已通过。

## 运行指标

质量：完成率、引用/工具正确率、人工接管；性能：首 token、P95 延迟、吞吐；成本：Token、模型费用、缓存命中；可靠性：错误率、超时、重试和队列；安全：注入、越权、泄露和副作用事件。

## 发布流程

```text
代码/Prompt/模型变更 → 审计与构建 → 离线评估
  → 灰度 → 线上指标与 trace → 扩大或回滚
```

本项目的文档发布入口是 `npm run publish`，它执行审计、VitePress 构建、Git 提交和推送；GitHub Actions 负责 Pages 部署。

## 故障处理

保留请求 ID、版本、工具轨迹、错误分类和用户影响；先停止副作用，再恢复队列或降级模型。不要只重试所有错误，也不要删除失败证据。
