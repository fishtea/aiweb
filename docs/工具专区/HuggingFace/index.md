# Hugging Face

Hugging Face 提供模型、数据集、评估、Transformers、推理和 Spaces 等生态能力。它是资源与工具平台，不代表每个模型都经过相同质量、安全或许可证审查。详情以[官方文档](https://huggingface.co/docs)和具体模型卡为准。

## 使用流程

1. 按任务、语言、模态和许可证筛选模型或数据集。
2. 阅读模型卡、数据来源、限制、评估和使用条款。
3. 在隔离环境加载，扫描依赖和权重，禁止不明代码自动执行。
4. 用真实评估集测试质量、显存、延迟、量化和安全。
5. 记录模型 revision、数据版本、配置和下载日期。

## 生态边界

- Transformers 负责模型加载和训练接口，不替代实验与部署设计。
- Datasets 负责数据访问，不替代授权、脱敏和质量治理。
- Hub 负责分发，不代表权重内容天然可信。
- Spaces 适合演示，生产部署需要独立的权限、网络和监控。
