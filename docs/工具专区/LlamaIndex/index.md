# LlamaIndex

LlamaIndex 是把外部数据接入 LLM 应用的框架，常用于解析、索引、检索、RAG 和 Agent 工作流。API 变化较快，请以[官方文档](https://docs.llamaindex.ai/)为准。

## 适合场景

文档加载、节点/元数据管理、向量和关键词检索、查询管线、Agent 工具和数据连接器。它是实现方式，不替代权限模型、评估和运维设计。

## 使用边界

- 先定义数据版本、权限、引用和更新策略，再选择索引组件。
- 服务端过滤租户和权限，不能让模型自行隐藏检索结果。
- 记录查询、召回文档、分数、Prompt、模型和最终引用。
- 对工具调用设置 schema、超时、重试、幂等和人工审批。

## 评估

分别测数据解析、召回 Recall@K、重排、答案忠实度、引用覆盖率、延迟和成本。框架升级时固定数据和模型做对照，不用单一示例判断质量。
