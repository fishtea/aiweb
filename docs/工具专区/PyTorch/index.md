# PyTorch

PyTorch 是深度学习训练、实验和部署生态的基础工具。它提供张量、自动微分、神经网络、数据加载、分布式和编译能力；具体版本以[官方文档](https://pytorch.org/docs/stable/)为准。

## 学习与工程路径

1. 用 Tensor、Dataset、DataLoader 和训练循环跑通小样例。
2. 理解 autograd、损失、优化器、验证和 checkpoint。
3. 再选择混合精度、编译、分布式、量化或部署后端。
4. 记录 Python、CUDA、驱动、PyTorch、模型和数据版本。

## 生产检查

- 固定环境并做 CPU/GPU、显存、吞吐和延迟压测。
- 测试断点恢复、随机性、数据加载瓶颈和异常样本。
- 对训练、评估和推理分别监控资源、质量和成本。
- 升级前运行固定回归集并保留旧环境。
