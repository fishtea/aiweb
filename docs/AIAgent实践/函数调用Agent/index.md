# 函数调用 Agent

函数调用把自然语言决策转换成结构化工具调用，是构建 Agent 最小、最容易验证的入口。本页聚焦 schema、执行器和错误闭环，不重复 Agent 总体理论。

## 适合场景

订单查询、天气查询、数据库读取、计算、表单草稿和其他边界清晰的 API 集成。涉及发送、删除、支付或权限变更时必须增加审批。

## 工具契约

```json
{
  "name": "search_orders",
  "description": "按用户授权范围查询订单",
  "parameters": {
    "type": "object",
    "properties": {"query": {"type": "string"}},
    "required": ["query"],
    "additionalProperties": false
  }
}
```

schema 只描述模型可以请求什么，服务端仍必须重新校验身份、权限、参数范围和资源归属。

## 执行闭环

1. 接收用户目标并决定是否需要工具。
2. 模型输出结构化工具名和参数。
3. 服务端校验 schema、权限、预算和幂等键。
4. 执行工具并把结构化结果作为 observation 返回。
5. 模型生成最终答复，引用工具结果而不是编造事实。

## 错误处理

| 错误 | 处理 |
| --- | --- |
| 参数错误 | 返回可修正字段，限制重试次数 |
| 权限不足 | 停止执行并要求授权，不让模型猜测 |
| 超时/限流 | 指数退避或降级，保留原任务状态 |
| 外部副作用未知 | 标记为不确定，禁止盲目重复提交 |
| 工具返回不可信文本 | 当作数据，不允许改变系统规则 |

## 验收指标

工具选择准确率、参数正确率、执行成功率、重复副作用率、平均步数、人工接管率和端到端延迟。测试集应包含正常请求、缺失字段、越权请求、注入文本和工具失败。
